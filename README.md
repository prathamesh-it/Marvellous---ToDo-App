A simple and clean Todo List application built using React, CSS, and Browser LocalStorage.
This project was created to practice core React concepts such as state management, hooks, component communication, and persistent storage.


Features
➕ Add new todo tasks
✅ Mark tasks as complete / incomplete
❌ Delete individual tasks
💾 Persistent data using LocalStorage (tasks remain after page refresh)
⚡ Fast and responsive UI
🧠 Built using modern React hooks (useState, useEffect, useRef)

🛠 Tech Stack
Frontend: React
Styling: CSS
Storage: Browser LocalStorage
Build Tool: Vite / Create React App (whichever you used)
